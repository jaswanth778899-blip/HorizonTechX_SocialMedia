# HorizonTechX Social Media Platform

A mini social media web application developed as part of the Horizon TechX Full Stack Development Internship.

## Features

- User registration and login
- JWT authentication
- Create posts
- View latest posts
- Like and unlike posts
- Add comments
- View comments
- User profiles
- Follow and unfollow users
- MongoDB database

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT
- Git & GitHub
